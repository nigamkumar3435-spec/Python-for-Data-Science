# Python for Data Science 🐍📊

Welcome to the **Python-for-Data-Science** repository! This repository is a comprehensive collection of code, notebooks, and projects documenting a complete journey into data science using Python. 

Whether it's data manipulation, numerical computing, or exploratory data analysis (EDA), this repository acts as a personal knowledge base and a practical guide for extracting insights from data.

## 📂 Repository Structure

The repository is organized progressively, starting from core library fundamentals to hands-on data analysis projects:

### 1. Numerical Computing
* **`NumPy_Basics/`**: Matrix operations, arrays, and fast numerical processing using NumPy.

### 2. Data Manipulation & Analysis
* **`Pandas_Fundamentals/`**: Series, DataFrames, data cleaning, handling missing values, and data aggregation.
* **`Data_Wrangling/`**: Techniques for transforming and mapping raw data into a usable format.

### 3. Data Visualization
* **`Matplotlib_Visuals/`**: Line charts, bar graphs, scatter plots, and foundational plotting.
* **`Seaborn_Advanced/`**: Statistical data visualization, heatmaps, and distribution plots.

### 4. Exploratory Data Analysis (EDA)
* **`EDA_Projects/`**: Complete Jupyter Notebooks performing end-to-end exploratory data analysis on various datasets (e.g., CSV, JSON, Excel).

## 🛠️ Tech Stack & Libraries
This repository utilizes the core Python data science ecosystem:
* **Python 3.x**
* **NumPy**
* **Pandas**
* **Matplotlib**
* **Seaborn**
* **Google Colab**
